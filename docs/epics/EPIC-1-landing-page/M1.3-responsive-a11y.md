# M1.3: Responsive and accessibility pass

## Goal
Ensure landing page works on mobile/tablet/desktop and meets basic accessibility (semantic HTML, keyboard navigation).

## In scope / Out of scope
- **In scope:** Responsive layout, semantic HTML, keyboard accessible nav, `lucide-react` icons, focus states.
- **Out of scope:** Real design polish, animations, imagery.

## Tasks
1. Test layout at common breakpoints.
2. Fix obvious layout breakage in RTL/LTR.
3. Ensure keyboard navigation for interactive elements.
4. Verify semantic structure and labels.
5. Use logical properties consistently.

## Acceptance criteria
| AC | Testable binary statement | Verification method |
|---|---|---|
| M1.3-01 | Landing renders without horizontal scroll on mobile | Browser dev tools (e.g. 375px width) |
| M1.3-02 | Navigation is keyboard accessible (tab/enter/space) | Manual keyboard test |
| M1.3-03 | Interactive elements have visible focus states | Visual/keyboard test |
| M1.3-04 | Semantic HTML used throughout (header/nav/main/footer/section) | Markup inspection |
| M1.3-05 | No layout-critical directional CSS; RTL/LTR correct at tested sizes | Inspect CSS/classes and visual check |

## Definition of Done
- All AC pass, build passes, Reviewer finds no CODE_RULES violations.
- Status updated in `STATUS.md`.
