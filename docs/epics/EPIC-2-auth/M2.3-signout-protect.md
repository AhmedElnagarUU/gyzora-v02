# M2.3: Sign out and route protection

## Goal
Implement sign out, ensure server-validated session, and protect dashboard route so unauthenticated users are redirected.

## In scope / Out of scope
- **In scope:** Sign out via API route handler, middleware/route protection for dashboard, server-side session validation. Use better-auth; no Server Actions.
- **Out of scope:** Roles, Site creation, dashboard content.

## Tasks
1. Implement sign out using existing auth system via API route handler (`src/app/api/**`).
2. Add protection for dashboard route (server-validated via middleware or server checks as per existing patterns).
3. Unauthenticated users redirected to sign in.
4. Authenticated users can access dashboard.
5. Ensure session invalidation is handled by better-auth.

## Acceptance criteria
| AC | Testable binary statement | Verification method |
|---|---|---|
| M2.3-01 | Authenticated user can sign out successfully | Manual test |
| M2.3-02 | Unauthenticated user accessing `/dashboard` is redirected to sign in | Manual test (logged out) |
| M2.3-03 | Authenticated user can access `/dashboard` | Manual test (logged in) |
| M2.3-04 | Protection uses server-validated session (not client-only) | Code inspection |
| M2.3-05 | After sign out, session is invalidated | Re-access protected route after sign out |

## Definition of Done
