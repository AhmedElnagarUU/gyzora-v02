# M4.1: Template schema and rendering

## Goal
Create the two approved templates as shared, structured definitions that render complete pages in both languages without placeholder text or false claims.

## In scope / Out of scope
- **In scope:** template structure, sample content, section layout, fallback handling, responsive rendering
- **Out of scope:** live project galleries or publishing logic

## Tasks
1. Review the existing template definitions and reuse them without inventing new ones.
2. Define structured section metadata and fallback content rules.
3. Implement rendering for Home, About, Services, Projects, Project Details, and Contact equivalents.
4. Add sample content labeling and graceful empty-state handling.

## Acceptance criteria
| AC | Testable binary statement | Verification method |
|---|---|---|
| M4.1-01 | Both templates render complete page structures in mobile and desktop layouts | Responsive browser check |
| M4.1-02 | Optional content and images do not break the layout | Browser validation |
| M4.1-03 | Placeholder or false claims are not present in template sample content | Manual design review |
| M4.1-04 | Template content remains separate from customer data | Code review and data model validation |

## Definition of Done
- Both templates are complete, usable, and cleanly render in EN and AR.
- Status updated in `STATUS.md`.
