# M4.2: Editor CRUD and save flow

## Goal
Implement the site editor for editing company info, services, features, text sections, and images while keeping updates draft-safe and reliable.

## In scope / Out of scope
- **In scope:** draft editing, validation, save feedback, section-based editing, image slot handling
- **Out of scope:** public publish logic or custom page builder features

## Tasks
1. Implement editor form and save flow for all editable site sections.
2. Validate user input server-side and cleanly surface errors.
3. Ensure saved content loads correctly on revisit.
4. Validate that edits do not mutate the shared template definition.

## Acceptance criteria
| AC | Testable binary statement | Verification method |
|---|---|---|
| M4.2-01 | A user can edit and save site content without publishing | Manual save flow |
| M4.2-02 | Saved content persists and is visible after revisiting the editor | Manual browser test |
| M4.2-03 | Invalid input is rejected with user-friendly error feedback | Validation test |
| M4.2-04 | Shared template content remains unchanged after edits | Code/data review |

## Definition of Done
- Editor is functional, persistent, and safe for use before publish.
- Status updated in `STATUS.md`.
