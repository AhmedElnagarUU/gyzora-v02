# M5.2: Preview and publish flow

## Goal
Provide preview and publish controls that let a customer review the draft Site and publish only when the content is valid, while keeping the last successful public version live until the next publish succeeds.

## In scope / Out of scope
- **In scope:** preview route, publish button, validation before publish, safe publication behavior
- **Out of scope:** custom domains, advanced scheduling, multi-environment deployment

## Tasks
1. Implement preview flow for draft or current saved state.
2. Validate draft Site content before publish.
3. Apply the simplest reliable publication model documented in code.
4. Ensure failed publish does not report success and old version remains public.

## Acceptance criteria
| AC | Testable binary statement | Verification method |
|---|---|---|
| M5.2-01 | Preview shows current draft content without publishing | Browser/manual check |
| M5.2-02 | Publish is rejected when validation fails | API validation test |
| M5.2-03 | Failed publish keeps the last successful version live | Failure simulation |
| M5.2-04 | Publish updates site content only after successful validation | Review and test |

## Definition of Done
- Preview and publish flows pass QA and preserve a safe public version.
- Status updated in `STATUS.md`.
