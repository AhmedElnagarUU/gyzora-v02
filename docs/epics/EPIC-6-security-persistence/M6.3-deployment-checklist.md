# M6.3: Deployment and production checklist

## Goal
Document the production prerequisites, environment setup, backup/rollback expectations, and launch checklist needed for a safe MVP release.

## In scope / Out of scope
- **In scope:** deployment prerequisites, env variables, rollback plan, launch checklist, known limitations
- **Out of scope:** large-scale enterprise operations or multi-region rollout

## Tasks
1. Document the required environment variables and deployment prerequisites.
2. Define the minimal backup and rollback process for the production environment.
3. Add the launch checklist and known limitations for the MVP.
4. Confirm the build and QA criteria before release.

## Acceptance criteria
| AC | Testable binary statement | Verification method |
|---|---|---|
| M6.3-01 | Required env vars and deployment prerequisites are documented | Documentation review |
| M6.3-02 | Launch checklist includes rollback, verification, and known limitations | Release review |
| M6.3-03 | Production build and QA gates are listed before signoff | Release signoff |
| M6.3-04 | No critical known issue remains untracked for launch | QA & PM review |

## Definition of Done
- Production deployment and rollback plan are complete, documented, and understood by the team.
- Status updated in `STATUS.md`.
