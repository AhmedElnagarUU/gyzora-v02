# M7.1: QA walkthrough and critical path verification

## Goal
Run the final QA walkthrough of the core MVP flow and confirm the PRD-critical user journey is working or explicitly blocked.

## In scope / Out of scope
- **In scope:** registration, login, dashboard, site creation, editing, projects, preview, publish
- **Out of scope:** non-MVP or future feature exploration

## Tasks
1. Run end-to-end verification of the critical user journey.
2. Confirm AR/EN and route behavior where relevant.
3. Record any blocker, risk, or unverified item that cannot be validated.
4. Keep the release gate evidence-based.

## Acceptance criteria
| AC | Testable binary statement | Verification method |
|---|---|---|
| M7.1-01 | Critical user journey passes end-to-end or is explicitly recorded as blocked | QA verification |
| M7.1-02 | AR/EN flows are checked where in scope | Browser QA |
| M7.1-03 | Any unverified acceptance criterion is explicitly documented | QA report |
| M7.1-04 | No critical issue remains hidden before launch | Release review |

## Definition of Done
- QA confirms the MVP path or flags unresolved blockers with evidence.
- Status updated in `STATUS.md`.
