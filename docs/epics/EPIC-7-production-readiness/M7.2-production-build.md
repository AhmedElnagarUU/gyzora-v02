# M7.2: Production build and deployment verification

## Goal
Verify the production build and environment assumptions are valid before sign-off, with explicit evidence for deployment readiness.

## In scope / Out of scope
- **In scope:** build verification, env handling, deployment prerequisites, rollback readiness
- **Out of scope:** future platform-scale or non-MVP improvements

## Tasks
1. Run the required production build and verify it passes.
2. Confirm env configuration and deployment prerequisites are documented.
3. Review rollback and recovery steps before launch.
4. Document any known limitations or open risks.

## Acceptance criteria
| AC | Testable binary statement | Verification method |
|---|---|---|
| M7.2-01 | Production build completes successfully | CI/build verification |
| M7.2-02 | Required environment variables are documented and understood | Environment checklist |
| M7.2-03 | Rollback path is documented in the launch plan | Release review |
| M7.2-04 | Known limitations are listed rather than ignored | Final QA board |

## Definition of Done
- Production readiness evidence is complete and launch prerequisites are tracked.
- Status updated in `STATUS.md`.
